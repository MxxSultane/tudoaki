## Passos: contagem estrutural, não ensaio cronometrado

| Intenção | Percurso actual | Proposta | Risco a observar |
| --- | --- | --- | --- |
| Criar tarefa pelo atalho de Hoje | Adicionar tarefa → escrever título → Guardar | Igual; a aparência não acrescenta passos | Não confundir o atalho com + global, que conserva Evento/Tarefa/Meta |
| Criar várias tarefas | Título → Guardar outra, conservando dia e associações | Igual à 4B; botão surge ao escrever/expandir | Descoberta da acção secundária e foco com teclado a 200% |
| Criar meta sem medida | FAB directo; preencher título e campos de métrica exigidos pelo editor | FAB → nome → Criar; dias opcional | Gate de dados e compreensão de Concluir quando alcançar; não prometer que v5 já o faz |
| Registar meta numérica | Métrica/alvo logo no formulário | Acompanhamento adicional → Com números → unidade/inicial/alvo → Criar | Mais divulgação para o modo numérico pode exigir um gesto extra; é escolha de complexidade por necessidade, não «menos passos para todos» |
| Registar movimento | Registar movimento → editor existente → Guardar | Igual, com acesso mais cedo na hierarquia | Não trocar editor por um formulário rápido que omita tipo/moeda/associação |
| Registar estudo | Planear estudo → editor académico → Guardar | Igual; Retomar é prioritário se existe foco activo | Não perder temporizador ao mudar o contexto |

Não foram medidos tempo, taxa de sucesso ou satisfação. Os ensaios automatizados demonstram propriedades do protótipo, não compreensão sem tutorial. O plano de pesquisa seguinte fecha essa lacuna sem apresentar opiniões do revisor como dados de utilizadores.
