# Interface actual versus proposta revista

A coluna Actual contém **capturas históricas reais do renderer Flutter** sobre dados sintéticos; a coluna Proposta contém **maquetas HTML conceptuais 4C.2**. Não são um diff pixel a pixel: as capturas reais têm 390×844 lógicos (algumas variantes 360×800/200%); as novas maquetas têm frame 360×800 CSS px e anotações de revisão exteriores. Datas/volumes de fixture podem diferir. Código de produção não mudou entre a base 4B e estes documentos.

As referências 3F/4A continuam válidas para os componentes que a 4B não alterou. As três correcções 4B (hábitos, FAB de Metas, criação rápida) são preservadas pelo código base e pelo contrato. A proposta de metas por tipo não é apresentada como capacidade já existente no v5.

Comparação com o **protótipo 4C.1**, separada da app: a medição Chromium encontrou 1255,1875 CSS px no contentor de Hoje da prancha longa; a 4C.2 usa 800 CSS px e scroll interno. A maquete financeira 4C.1 tinha zero selects; a revista tem um selector explícito de moeda e mês separado. A escolha de Com números da 4C.1 não revelava os campos de medição completos; a revista revela unidade/inicial/alvo. Estas são correcções de fidelidade dos artefactos, não falhas novas de produção.
